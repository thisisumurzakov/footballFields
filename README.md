# Football Field Booking System

## Overview

This project is a backend API for a football field booking system. The system allows users to view available football fields, book them for specific times, and manage those bookings. There are different roles in the system with various permissions, including admin, field owners, and regular users.

### Key Features:
- **Admin**: Has full permissions over all fields and bookings.
- **Field Owners**: Can manage their football fields (add, edit, delete fields) and view/manage bookings.
- **Users**: Can view available football fields and make bookings during available times.

The project is built using **Django** and **Django REST Framework**.

---

## Задача

Данный проект представляет собой бэкенд API для системы бронирования футбольных полей. Система позволяет пользователям просматривать доступные поля, бронировать их на определённое время и управлять своими бронированиями. В системе есть разные роли с различными правами: администраторы, владельцы полей и обычные пользователи.

### Основные функции:
- **Администратор**: Имеет полные права на управление полями и бронированиями.
- **Владельцы полей**: Могут управлять своими полями (добавление, редактирование, удаление полей) и просматривать/управлять бронированиями.
- **Пользователи**: Могут просматривать доступные футбольные поля и бронировать их на свободное время.

Проект построен на **Django** и **Django REST Framework**.
